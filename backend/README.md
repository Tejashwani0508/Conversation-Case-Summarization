# Backend

This backend contains the FastAPI application, configuration, and initial database setup for the Conversation & Case Summarization project.

## Structure

- `app/` - FastAPI application code
- `app/config/` - environment and application settings
- `app/database/` - SQLAlchemy database configuration
- `app/models/` - domain models (reserved for later)
- `app/schemas/` - Pydantic schemas (reserved for later)
- `app/api/` - API route modules (reserved for later)
- `app/services/` - business logic services (reserved for later)
- `app/repositories/` - data access repositories (reserved for later)
- `app/prompts/` - prompt management and templates (reserved for later)
- `tests/` - backend test suites
